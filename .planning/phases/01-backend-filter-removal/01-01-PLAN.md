**Step A — Create scripts/flush_stale_cache.py**

Create the directory `scripts/` if it does not exist. Write the file:

```python
#!/usr/bin/env python3
"""
flush_stale_cache.py — Delete all analysis:, export:, and blueprint: Redis keys.

Run once at deploy before the API starts to prevent stale filtered results
from being served as cache hits after the FILT-01/FILT-02 filter removal.

filedf: keys (per-file parsed DataFrames) are intentionally preserved — they
contain raw data, not filtered results, so they remain valid.
"""
from __future__ import annotations

import os
import sys

import redis


PREFIXES = ("analysis:", "export:", "blueprint:")


def main() -> None:
    redis_url = os.environ.get("REDIS_URL", "redis://localhost:6379")
    r = redis.from_url(redis_url, decode_responses=False)

    try:
        r.ping()
    except redis.ConnectionError as exc:
        print(f"[flush] ERROR: cannot reach Redis at {redis_url}: {exc}", file=sys.stderr)
        sys.exit(1)

    total_deleted = 0
    for prefix in PREFIXES:
        cursor = 0
        while True:
            cursor, keys = r.scan(cursor, match=f"{prefix}*", count=500)
            if keys:
                deleted = r.delete(*keys)
                total_deleted += deleted
                print(f"[flush] deleted {deleted} keys with prefix '{prefix}'")
            if cursor == 0:
                break

    print(f"[flush] done — {total_deleted} keys removed.")


if __name__ == "__main__":
    main()
```

**Step B — Update docker-compose.yml**

Add a `cache-flush` one-shot service that runs before `api`. The `api` service's `depends_on` must be updated to wait for both `redis` AND `cache-flush` to complete successfully.

Write the new docker-compose.yml (preserve all existing fields; only add the cache-flush service and update api.depends_on):

```yaml
services:
  cache-flush:
    build: .
    command: python scripts/flush_stale_cache.py
    env_file: .env
    depends_on:
      - redis
    restart: "no"

  api:
    build: .
    ports:
      - "8000:8000"
    env_file: .env
    depends_on:
      redis:
        condition: service_started
      cache-flush:
        condition: service_completed_successfully
    restart: unless-stopped
    volumes:
      - ./data:/app/data:ro

  redis:
    image: redis:7-alpine
    restart: unless-stopped
    volumes:
      - redis_data:/data

volumes:
  redis_data:
```

Note: `restart: "no"` on cache-flush ensures it runs exactly once per `docker-compose up`. `service_completed_successfully` means `api` will not start until the flush exits 0.
